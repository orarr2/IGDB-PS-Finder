# Project conventions

## Commit / PR authorship — STRICT

NEVER mention the AI assistant anywhere in this repository. Specifically:

- Do **not** add `Co-Authored-By` trailers for the assistant.
- Do **not** add any `Claude-Session`, `Generated with`, or similar lines to
  commit messages or PR descriptions.
- Do **not** reference the assistant, the model, or its name in commit
  messages, PR titles/bodies, code comments, or any other committed artifact.

Commit messages must read as if written by the repository owner only. This
applies to every commit and PR, with no exceptions, permanently.
